# 🍅 뽀모도로 위젯 (Pomodoro Widget)

항상 화면 맨 위에 떠 있는 **미니 사이즈 뽀모도로 타이머 + 할 일 노트** 데스크톱 위젯입니다.
다른 창을 클릭해도 위젯이 뒤로 숨지 않아서, 공부하거나 작업하면서 시간과 할 일을 계속 눈에 두고 쓸 수 있어요.

## ✨ 기능

- **원형 뽀모도로 타이머** — 시계 안에서 빨간 부채꼴이 줄어들며 남은 시간을 보여줍니다.
  - 5 / 15 / 30 / 45 / 50분 프리셋 버튼
  - 시계를 **드래그**해서 원하는 시간 직접 설정
  - 시계 중앙에 커서를 올리면 **일시정지(⏸) / 재개(▶)** 버튼이 나타남
  - 시간이 끝나면 창 전체가 **빨갛게 깜빡이고** 알림음이 울림
- **할 일 노트** — 공책 스타일 목록. 맨 아래 반투명 줄에 바로 타이핑해서 추가, 동그라미를 눌러 완료 체크
- **완료 처리 방식 선택** — 완료한 일을 아래로 내리거나 / 제자리에 줄만 긋거나 / 자동 삭제
- **7가지 테마** — 크림, 화이트, 그레이, 블루, 퍼플, 핑크, 다크
- **항상 위에 표시(Always on Top)** — 어떤 창을 클릭해도 위젯이 항상 보임
- **자유 이동 · 최소화 · 닫기** — 상단바를 잡고 드래그, 오른쪽 위 버튼으로 최소화/종료
- **자동 저장** — 컴퓨터를 껐다 켜도 할 일과 설정이 그대로 유지됨

## 📥 설치 및 실행

### 방법 A. 그냥 바로 실행하고 싶다면 (권장 · 개발 지식 불필요)

1. **`PomodoroWidget 1.0.0.exe`** 파일 하나만 내려받으세요. (`dist` 폴더 안 / 또는 릴리스에 올려둔 파일)
2. 더블클릭하면 바로 실행됩니다. 별도 설치 과정이 없습니다.
3. 처음 실행 시 Windows가 파란 화면으로 **"Windows의 PC 보호"** 경고를 띄울 수 있어요.
   → **[추가 정보]** 클릭 → **[실행]** 을 누르면 됩니다.
   (개인이 만든 앱이라 유료 인증서 서명이 없어서 뜨는 경고일 뿐, 안전합니다.)
4. 컴퓨터를 켤 때마다 자동으로 뜨게 하려면: `Win + R` → `shell:startup` 입력 → 열린 폴더에 exe 바로가기를 넣어두세요.

> 💡 **이 exe는 Windows 전용입니다.** Mac에서 쓰려면 아래 "방법 B"로 소스코드를 받아 실행해야 합니다.

### 방법 B. 개발자용 (소스코드로 실행 · Windows/Mac 공통)

[Node.js](https://nodejs.org) 가 설치되어 있어야 합니다.

```bash
# 1. 저장소 내려받기
git clone <이 저장소 주소>
cd pomodoro_timer

# 2. 필요한 패키지 설치 (최초 1회)
npm install

# 3. 실행
npm start
```

Windows용 exe를 직접 빌드하려면:

```bash
npm run dist
# 결과물: dist/PomodoroWidget 1.0.0.exe
```

## 📂 어떤 파일을 받아야 하나요?

| 목적 | 받을 것 |
|---|---|
| **그냥 프로그램만 쓰고 싶다** | `PomodoroWidget 1.0.0.exe` **이 파일 하나만** |
| **코드를 보거나 직접 고치고 싶다** | 저장소 **전체** (`main.js`, `renderer/` 등) |

`node_modules`, `dist` 폴더는 내려받을 필요가 없습니다. (설치·빌드하면 자동으로 생겨요.)

## 🛠 기술 스택

- **Electron** — HTML/CSS/JavaScript로 만든 데스크톱 앱. "항상 위에 표시" 같은 기능 때문에 웹이 아닌 데스크톱 앱으로 제작
- 외부 프레임워크·데이터베이스 없음. 할 일/설정은 사용자 폴더의 **JSON 파일**로 저장

## 📁 폴더 구조

```
pomodoro_timer/
├── main.js            # 앱 창을 만들고 파일 저장/불러오기를 담당
├── preload.js         # 화면과 시스템 사이 안전한 다리 역할
├── renderer/          # 실제 화면 (보이는 부분)
│   ├── index.html     # 화면 구조
│   ├── styles.css     # 디자인 (색·모양)
│   ├── timer.js       # 타이머 기능
│   ├── todo.js        # 할 일 기능
│   └── settings.js    # 설정 기능
├── build/icon.ico     # 앱 아이콘 (토마토)
└── package.json       # 앱 정보와 실행 명령어
```

## 💾 내 데이터는 어디에 저장되나요?

- **Windows**: `%APPDATA%\PomodoroWidget\` 폴더 안
  - `todos.json` — 내가 적은 할 일 목록
  - `settings.json` — 테마·소리 등 설정
- 이 파일들은 프로그램(exe)과 **별개로** 저장되기 때문에, exe를 다른 곳으로 옮기거나 새 버전으로 바꿔도 할 일은 그대로 남아 있습니다.
